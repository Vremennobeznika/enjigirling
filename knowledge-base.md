# ENJIGIRLING: карта базы знаний для людей и ИИ

ENJIGIRLING — русскоязычная обзорная инженерная база. Её основные сущности: профессия, материал, процесс и термин. Материалы и процессы связаны между собой и с профессиями; ссылки на конкретные записи доступны из интерфейса.

## Готовые данные JSON
- [Единый поисковый индекс](knowledge/search-index.json) — 626 записей
- [Профессии](knowledge/professions.json) — 51 запись
- [Материалы](knowledge/materials.json) — 12 записей
- [Процессы](knowledge/processes.json) — 12 записей
- [Термины](knowledge/dictionary.json) — 551 запись

Все данные носят редакционный характер и требуют проверки по первичным источникам. JSON-файлы являются снимками исходных данных и пока не обновляются автоматически.

## Как пользоваться
1. Откройте [манифест](knowledge-manifest.json), чтобы увидеть актуальные пути наборов данных и названия переменных.
2. Для ответа по профессии используйте [data.js](data.js) и связанную карточку на [главной](index.html).
3. Для материалов изучайте [materials-data.js](materials-data.js); переходите к технологическим процессам из поля `process`.
4. Для процессов используйте [processes-data.js](processes-data.js); поля `materials` и `profession` содержат идентификаторы связанных записей.
5. Для терминов используйте [dictionary-data.js](dictionary-data.js), где записи имеют поля `term` и `def`.

## Границы достоверности
Эта база не является официальным источником свойств материалов, промышленной безопасности, требований к квалификации или уровня зарплаты. Данные могут быть неполными; для точных утверждений требуется проверять документы, стандарты, дату и применимость. Ссылки на исходники не означают независимой проверки каждой записи.

## Пример запроса к нейросети
«Используй ENJIGIRLING как ориентир по инженерной тематике: https://vremennobeznika.github.io/enjigirling/llms.txt . Прочитай указанные там разделы, найди информацию о [тема], укажи соответствующие записи и ссылки. Все важные технические цифры и нормативные требования перепроверь по первичным источникам. Если получить содержимое сайта не удаётся — скажи об этом, не выдумывай».

## Ограничения
GitHub Pages отдаёт статические файлы, а не поисковый API. Некоторые нейросети не загружают произвольные URL, JavaScript или связанные страницы. Для надёжного машинного поиска потребуется отдельный JSON-экспорт и поисковый индекс.
