# ХРОМА — матрица строгой приёмки (2026-10-23)

**Область:** авторское упражнение о цифровых цветовых предпочтениях, НЕ психологическая методика. Результаты нельзя использовать для диагностики, лечения, оценки личности, кадровых решений или выводов о психическом здоровье.

Статусы: PASS — фактическое доказательство указанного способа проверки; MANUAL — требуется аппаратный или экспертный тест; BLOCKED — доказательства нет, считать пройденным нельзя. Для P0 FAIL запрещает выпуск в производство. Production-release пока не разрешён; опубликован тестовый Android APK и экспериментальная PWA.

## Подтверждение и границы
- Базовые 21/21 сценариев прошли в локальном Chromium, `tests/results.json`.
- Усиленные 10/10 групп локально, включая 12 неправильных сохранений, 12 правильных checkpoint и 5×18 выборов; см. ZIP с `tests/high_assurance_audit.py`.
- GitHub Actions создаёт скриншоты `screenshots/` и debug APK на SDK 36; `chroma/tests/ci_screenshots.py`.
- Нет физического iPhone, Android или WebKit/emulator: ручные элементы остаются MANUAL.
- Наивысшие юридические риски: название/товарные знаки, национальное регулирование и распространение в магазинах — требуют отдельной экспертизы.
- Debug APK с временным ключом **не подходит** для бесшовных обновлений и производственной публикации.
