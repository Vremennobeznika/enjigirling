# ХРОМА · Цветовой выбор

**Лёгкое автономное PWA** для iPhone, Android и старых компьютеров. Авторское упражнение для сравнения субъективных предпочтений — **не тест Люшера**, не медицинская и не психологическая диагностика.

## Что внутри

- 9 самостоятельно подобранных оттенков; 2 последовательных раунда по 9 выборов.
- Сравнение позиций, отмена, повторное прохождение, сохранение текстового результата.
- Тёмная и светлая темы с сохранением выбора.
- Без сервера, учётных записей, трекеров, рекламы, внешних шрифтов, фреймворков и API.
- Хранение промежуточных результатов только в `localStorage` устройства, без передачи по сети.
- Манифест PWA, сервис-воркер для офлайн-работы после успешного первого открытия через HTTPS/localhost.
- Интерфейс для экранов от 320 CSS-пикселей, портретной и горизонтальной ориентации.

## Установка

**iPhone / iPad:** открыть HTTPS-адрес в Safari → «Поделиться» → «На экран Домой» → «Добавить». При наличии переключателя включить «Открывать как веб-приложение». На старых версиях iOS названия и доступность пунктов отличаются.

**Android:** открыть в Chrome → меню браузера → «Установить приложение» или «Добавить на главный экран». Наличие установщика зависит от браузера/системы.

**Без установки:** просто открыть ссылку в браузере. Чтобы офлайн-режим заработал, необходимо первый раз открыть опубликованную версию онлайн и разрешить сохранение данных сайта.

## Запуск из ZIP без сборки

1. Распаковать папку целиком, сохраняя структуру.
2. Для просмотра HTML открыть `index.html` (без установки и офлайн-кэша).
3. Для корректного PWA-режима выполнить в папке проекта: `python -m http.server 8000`, затем открыть `http://localhost:8000/`. На мобильных требуется опубликованный HTTPS-сайт.

## GitHub Pages

В отдельном публичном репозитории разместить **содержимое папки** в корне ветки `main`. GitHub → `Settings` → `Pages` → `Deploy from a branch` → `main` и `/(root)` → `Save`.

Если проект опубликован как **папка существующего Pages-репозитория**, пути `./` в манифесте и коде работают независимо от его URL-префикса. Не переносите содержимое вне папки без проверки пути.

## Проверка и зависимости

Страница: HTML + CSS + ванильный JS. Для использования и установки не нужны Node.js или сборщик.

На компьютере с установленным Playwright и Chromium: `python tests/check_app.py`. Скрипт тестирует интерактивность и размеры окон через встроенные HTML/CSS/JS, поскольку среда проверки может запрещать сетевую навигацию браузера. **Это НЕ тест на физических iPhone/Android и не полноценная проверка service worker в установленном PWA.** Итоги: `tests/results.json`.

Отдельный тест service worker: `node tests/check_worker.js`.

## Файлы

- `index.html` — интерфейс, доступность, метатеги.
- `styles.css` — адаптивные темы и размеры.
- `app.js` — логика выбора, сравнения, локального хранения и экспорта.
- `sw.js` / `manifest.webmanifest` — PWA.
- `assets/` — оригинальные иконки.
- `tests/` — матрица проверок, автотесты и контрольные скриншоты.
