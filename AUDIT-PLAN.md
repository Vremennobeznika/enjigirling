## Правила

- **PASS** — проверка действительно выполнена; **FAIL** — подтверждённый дефект; **FIXED / RETEST NEEDED** — код исправлен, браузерный повтор ещё не подтверждён; **REVIEW** — требуется содержательная проверка; **NOT RUN** — выполнение не подтверждено.
- Порядок: P0 функциональность и публикация → P1 вёрстка и доступность → P1 данные/источники → P2 улучшения UX.
- Не удалять существующие разделы, 51 профессию, 551 термин, 12 материалов и 12 процессов. Все стили — монохромные, без синих ссылок.
- Каждая задача закрывается только с доказательством: команда/результат, commit, ссылка на Actions либо запись о невозможности проверки.

## Подтверждённые результаты и дефекты

1. **FIXED / RETEST NEEDED:** в двух GitHub Actions workflow статическая проверка передавалась через `tee` без `pipefail`. Исправлено; добавлен регрессионный тест.
2. **FIXED / RETEST NEEDED:** восемь HTML-страниц не имели keyboard skip-link. Теперь все девять содержат ссылку и цель `#main-content`; добавлена проверка в статическую матрицу.
3. **PASS — проверка данных в ограниченной среде:** 626 записей, 5 зарегистрированных источников, 7 ссылок на источники, 0 `claim_checked`; `build-quality --check`, `check-evidence`, `audit-knowledge --strict` выполнены с результатом PASS при чтении актуальных файлов через GitHub connector.
4. **NOT RUN:** полный Node.js/Playwright и реальный HTTP smoke не выполнены в доступной среде. Нельзя объявлять зелёный CI без фактических логов.
5. **Долг по достоверности:** 619 из 626 записей не имеют ссылок на источники. Наличие ссылки не означает проверки технического утверждения.

## Проверка статической безопасности от 21.10.2026

- Проверка добавлена в `tests/full-matrix.cjs`, коммит `f85093c92d7416c324416c25c0d2dcd5e0ded8db`.
- Все девять страниц подключают `section-ui.css` со стилями `.skip-link`; проверено по исходникам.
- Это не заменяет динамический аудит DOM, сканирование секретов или запуск браузерных сценариев.
