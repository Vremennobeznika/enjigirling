# Инженерная академия — матрица приёмки и реестр рисков

Статус: **НЕ ГОТОВО К ПУБЛИКАЦИИ**. Ветка `draft/engineering-academy` предназначена для разработки. Запрещено сливать её в `main` без отдельного разрешения владельца.

## Исходное состояние и архитектура

- Основной сайт: статические HTML/CSS/JavaScript, GitHub Pages.
- Базовый практикум: `engineering-lessons.html` + `engineering-lessons.js`, 3 темы / 6 заданий.
- Дополнительные черновики: `academy-draft.html`, `academy-draft-part2.html`, `academy-draft-part3.html`, 13 + 12 + 24 = **49 тем**, 26 + 24 + 48 = **98 заданий**.
- Итого в разработке: 52 темы / 104 задания. **Количество тем не равно качеству полноценного курса.** Пока это короткие учебные карточки с двумя задачами, а не предметно аттестованные курсы.
- Три независимых обработчика форм дублируют логику. Риск рассинхронизации исправлений — P1.
- Прогресс хранится в `localStorage`, разделён по страницам. Экспорт, перенос между устройствами и разрешение конфликтов вкладок отсутствуют — P1.
- Браузерная навигация между частями есть, но полноценный единый каталог, фильтры и поиск отсутствуют — P1.

## Применимость проверок

- **Unit:** применимо, проверки чисел и валидации; тестировать.
- **Integration:** применимо, HTML-формы ↔ JS ↔ localStorage; тестировать.
- **E2E, regression, negative, boundary, reliability, data integrity:** применимо, ещё не подтверждено.
- **Security:** применимо к пользовательскому вводу, HTML и хранению; секреты для статического практикума не нужны.
- **Compatibility, accessibility, localization, offline, performance, UX:** применимо; измерений и наблюдений пока нет.
- **Load/stress сервера, p95/p99 серверных запросов:** не применимо к статическому локальному решателю без серверной бизнес-логики; нагрузка браузера всё равно требует проверки.
- **Реальные пользовательские исследования:** не выполнены, участников нет; экспертная оценка не заменяет наблюдение.
- **APK/подпись мобильного пакета:** не применимо, продукт — сайт.

### Правило выпуска

Выпуск **BLOCKED**, пока любой P0/P1 gate имеет статус PARTIAL, BLOCKED или NOT RUN. Прогон тестов и количество уроков не заменяют проверку источников и E2E. При каждом изменении указывать SHA, URL CI, затронутые gate, воспроизводимый тест, результат и оставшийся риск. Не повышать статус автоматически после успешного CI.
