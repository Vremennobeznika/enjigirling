# СЛОИ — веб-приложение 1.2.0

Приватный дневник состояния, настраиваемый трекер настроения для iPhone, Android и компьютера. Основная версия распространяется как **PWA**: APK не требуется.

**Открыть:** https://vremennobeznika.github.io/enjigirling/mood-layers/

## Установка

- **iPhone / iPad:** открыть ссылку в Safari → «Поделиться» → «На экран Домой» → «Добавить».
- **Android:** открыть ссылку в Chrome → меню ⋮ → «Установить приложение» или «Добавить на главный экран».
- **Компьютер:** Chrome или Edge → значок установки в адресной строке или пункт меню «Установить приложение».
- В самом приложении есть кнопка установки и инструкция, адаптированная для платформы.
- Сначала необходим интернет для загрузки файлов. После успешного кэширования в Service Worker приложение доступно офлайн.
- При обновлении приложение не перезагружается автоматически. Пользователь подтверждает переход на новую версию, чтобы заметка в форме не пропала внезапно.

## Сохранение и приватность

- Записи, настройки и пользовательские состояния в `localStorage` **этого браузера на этом устройстве**; нет аккаунтов, сервера данных, аналитики, API и отправки дневника.
- Другой браузер, другое устройство и отдельная установленная копия PWA **не получают** эти записи автоматически. Облачной синхронизации нет.
- Экспорт JSON/CSV и импорт JSON доступны в «Настройках». Необходимо регулярно сохранять отдельную резервную копию JSON вне браузера: при очистке данных, удалении PWA или поломке устройства дневник может пропасть.
- В прошлых Android APK данные хранились отдельно. Для переноса экспортируйте JSON **в старой APK**, затем импортируйте в PWA.
- Хранилище не зашифровано самим приложением. Защитите устройство и резервные копии.

## Возможности

Настроение 1–7, тревога/энергия/напряжение/боль 0–10; собственные состояния (до 100), история, заметки, сон, терапия, приём препаратов, менструация, физическая активность, графики и две темы. Приложение не ставит диагнозов и не оценивает эффективность лечения.

## Технические ограничения

- Сайт раздаёт только статические HTML/CSS/JS и иконки; сами записи в сеть не отправляются.
- Service worker кэширует **только статические ресурсы**, не записи и не экспортируемые JSON.
- Браузер или система могут очистить локальное хранилище; отдельные устройства надо тестировать физически.
- Напоминания показываются при открытии: фоновых уведомлений нет.
- Способ установки и изоляция данных могут отличаться между браузерами и версиями iOS/Android.
- Код распространяется без сторонних библиотек и внешних шрифтов; полностью безотказная работа не гарантируется.

## Проверка

Синтаксис JavaScript проверяется через `node --check`. Матрица Chromium проверяет создание записи, историю, переключение темы, установочные подсказки и адаптивную вёрстку. Модульная проверка Service Worker не заменяет настоящий офлайн-запуск на физическом устройстве.
