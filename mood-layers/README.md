# СЛОИ — дневник состояния

Приватный локальный трекер настроения: PWA для iPhone и Android, автономная Android WebView-сборка для Android 6.0+.

## Возможности

- Самооценка настроения 1–7; тревога, энергия, напряжение, боль 0–10
- До 100 собственных названий состояний, в том числе грубые или личные слова
- Записи сна, событий психотерапии, отметки приёма назначенных препаратов, активности, менструации
- История и редактирование, поиск, графики с реальными пропусками и описательная статистика
- Дневник; отключённые по умолчанию **словарные подсказки** по словам заметок, не ИИ и не диагноз
- Экспорт/импорт JSON и CSV; в Android APK — системный файловый диалог
- Светлая и тёмная темы, без внешних зависимостей, данных на серверах и трекеров
- Две проверяемые резервные контрольные точки данных в localStorage, восстановление после одной повреждённой записи

## Развёртывание

Разместите каталог под HTTPS (например, GitHub Pages `/mood-layers/`). На iPhone откройте Safari → «Поделиться» → «На экран Домой». На Android через Chrome выберите «Установить приложение». Понятие установки PWA зависит от версии ОС и браузера. Один HTML-файл без сайта не обеспечивает полноценный офлайн PWA.

Для Android APK: workflow `.github/workflows/mood-android.yml` в корне репозитория собирает **debug APK**. Это тестовая сборка с нестабильным debug-ключом, не релиз для Play Market. Отдельной нативной сборки iOS/IPA нет.

## Риски и ограничения

- Никакая серия тестов не может гарантировать абсолютное отсутствие ошибок.
- localStorage **не зашифрован** и может очищаться системой; рекомендуется регулярно экспортировать JSON и защищать устройство паролем.
- Напоминание показывается при открытии приложения, **нет фонового push**.
- Описательное сравнение оценок после терапии или приёма препаратов **не доказывает пользу или вред**. Никаких советов менять дозы или прерывать лечение.
- Правовые медицинские и privacy требования для публикации в магазинах требуют отдельной проверки по юрисдикции.
- Автоматические подсказки по словам дают ложные срабатывания и не способны определять психологические кризисы.

## Тестирование

`python3 tests/static_matrix.py`; `python3 tests/browser_matrix.py` при установленном Playwright/Chromium. Результаты включены в `tests/RESULTS.json` и `TEST_MATRIX.md`. Проводите реальное испытание на физических iPhone/Android, с TalkBack, VoiceOver и режимом нехватки памяти. Только после этого принимать решение о широком распространении.
