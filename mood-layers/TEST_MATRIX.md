# Матрица приёмки — СЛОИ v1.0

Обозначения: PASS — реально проверено, FAIL — воспроизведённая ошибка, BLOCKED — технически невозможно проверить в среде, MANUAL — нужны физическое устройство или специалист.

| Группа | Пункты | Условия допуска |
|---|---|---|
| Данные | сохранение, повторная загрузка, выбор актуального слота, обрыв записи, повреждённый checksum, полное заполнение памяти | Никакие неподтверждённые сохранения не выдаются как успешные |
| Валидация | шкалы, нулевая и пустая оценка сна, дата, 100 состояний, длина заметок, импорт JSON с неверной схемой | Некорректные данные отклоняются |
| История | новая запись, редактирование, удаление, поиск, сортировка, фильтр периода | Нет дублей и подменённых дат |
| Графики | отсутствие данных, одна запись, повторяющиеся даты, 7/30/90 дней, числовая шкала | Нет придуманной интерполяции отсутствующих дней |
| Приватность | нет сетевых SDK, разрешений Android, XSS через собственные ярлыки, CSV injection, экспортные файлы | Данные не отправляются наружу |
| Интерфейс | 280,320,360,375,390,430,768,1024 px; 200% текст; светлая/тёмная тема; горизонтальная ориентация; длинные слова | Нет горизонтального переполнения, кнопки доступны |
| Доступность | keyboard, фокус, aria-live, контраст, reduced-motion, VoiceOver, TalkBack | Без ловушек фокуса; реальные screen readers — ручная проверка |
| Android | офлайн assets, установка, экспорт JSON/CSV, закрытие WebView, повторный запуск после renderer crash | Не более 2 автоматических перезапусков в минуту, далее экран восстановления |
| Безопасность | приложение не ставит диагнозы; нет графиков «эффективности лечения» с причинными утверждениями | Только самонаблюдение, оговорки в интерфейсе |
| Подпись | digest APK, JAR verification, v2/v3 apksigner, фиксированный release keystore | Debug не считается release-аттестацией |

**Блокеры для релизной аттестации**: физические испытания на iPhone/Android; проверка ОС 6–16; screenreader; доказательство восстановления в системном WebView; финальный signing key; privacy/legal review; длительный тест записи/удаления. Не разрешать рекламировать это как диагностическое медицинское приложение.
