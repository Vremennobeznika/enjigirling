# PSHO — динамическая проверка интерфейса (23.10.2026)

Проверена опубликованная логика версии **1.3.0**. Исходники HTML/JS/PWA и манифест сверены с GitHub по Git blob SHA, локальные проверочные файлы включены в ZIP.

| Набор | Результат |
|---|---:|
| Быстрые взаимодействия, темы, размеры, сохранение, перезапуск | 101/101 PASS |
| Экспорт/импорт, записи, валидация и защита текста | 29/29 PASS |
| Инъекции отказа хранилища, восстановление и ошибка интерфейса | 11/11 PASS |
| Модульный тест установки/активации service worker | PASS |

**Исправлено:** повторный быстрый submit не создаёт лишние записи; намеренный новый ввод не блокируется. Название интерфейса, манифеста и установки — **PSHO**.

**Совместимость:** прежняя URL-папка `mood-layers`, PWA id/scope, префикс локального хранения `sloi-v1-` и формат резервных копий `SLOI_BACKUP_V1` сохранены во избежание потери данных.

**Не подтверждено:** физические iPhone/Android, WebKit, настоящий офлайн-запуск через установленный service worker. Попытка проверить локальный HTTP-сайт в Chromium заблокирована средой с `ERR_BLOCKED_BY_ADMINISTRATOR`. Старый прогон на 115 пунктов после исправления кнопки подвис, поэтому новая приёмка основана на независимых успешных наборах выше.

Нет гарантии нулевых отказов. Тесты не являются медицинской, юридической либо официальной аттестацией.
