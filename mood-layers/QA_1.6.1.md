# ПШО 1.6.1 — расширенная проверка

Объект: ПШО из `mood-layers`, а не остальные разделы инженерного сайта. Синтетические записи; пользовательские дневники не использовались.

## Найденные дефекты и изменения

- **P0, Android:** завершение процесса сразу после сохранения могло потерять последние изменения WebView localStorage. Теперь подтверждение следует после атомарной записи основного снимка в приватный файл приложения, `fsync` и проверки чтением. Старые данные читаются из прежнего хранилища до первого успешного сохранения. JSON и очистка данных работают с тем же основным снимком.
- **P1, старый WebView:** в образе Android 6 отсутствуют Array.find/findIndex. Добавлены небольшие полифилы без новой библиотеки. Непатченная 1.5 на этом образе не сохраняет дневник; её миграция на API 23 проверяется с явно обозначенной фикстурой старого формата.
- **P2, доступность:** недостаточный контраст навигации при наведении в светлой теме; исправлен цвет. При уменьшенном движении отключена плавная прокрутка. Постоянная анимация совы удалена.

## Ограничения

Физические Android/iOS, настоящий скринридер, клиническая валидация формулировок шкал и устойчивость к отключению питания устройства не проверены. Большой архив содержит короткие синтетические тексты; максимально длинные заметки ограничиваются реальной квотой устройства. Обновление APK с другим сертификатом не подтверждается испытанием с одинаковым тестовым ключом. Общие проверки инженерного сайта имеют отдельные ошибки каталога вне ПШО.

## Испытания Android и итог

- **Android 15 / API 35:** полный цикл установки, обновления, немедленного force-stop, экспорта через системный диалог, очистки, импорта и повторного перезапуска — PASS. [Запуск и доказательства](https://github.com/Vremennobeznika/enjigirling/actions/runs/43540601412), успешная задача `device-qa (35)`.
- **Android 6 / API 23:** установка, чтение старого формата, проработка, оба опросника и сохранность после force-stop — PASS. Полный системный экспорт/импорт **не подтверждён**: автоматизация не смогла выбрать доступную для записи папку в старом DocumentsUI; кнопка Save осталась отключена. Это не записано как успешная проверка. [Последний запуск](https://github.com/Vremennobeznika/enjigirling/actions/runs/43541058373), задача `device-qa (23)`.
- Профильные PSHO quality и universal PWA проверки PR #43 — PASS на коде приложения `5b698c518d5f0ec4311421885884a8c443802c4c`. Общий Site checks имеет отдельную ошибку инженерного каталога, не исправлявшегося в этой задаче.
- Выдаваемый APK: 1.6.1 (code 8), подписанная debug-сборка `app.layers.mood`; файлы приложения внутри APK побайтно сверены с исходниками. [Скачать APK в ZIP](https://github.com/Vremennobeznika/enjigirling/actions/runs/43541058373/artifacts/14092386202). Подпись и целостность проверены в CI. Установленная на эмуляторах сборка получена из того же кода с ключом соответствующей задачи CI; её сертификат отличается от сертификата артефакта задачи `build`.

**Вердикт: ГОТОВО С ОГРАНИЧЕНИЯМИ как тестовая сборка.** Подтверждения полного цикла резервного копирования на штатном Android 6, физического устройства и клинической валидации нет. APK с другой подписью нельзя считать проверенным обновлением прежней установленной сборки; перед установкой нужен экспорт JSON из старого приложения.
