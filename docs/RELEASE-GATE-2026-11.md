# Release gate и материалы Telegram / Synapse

Дата ввода процесса: 2026-11-23. **Статус документа: правило процесса, НЕ свидетельство прохождения тестов.**

## Защита приватности
- PUBLIC: собственные проверенные тексты, код и ресурсы с установленными правами.
- INTERNAL: планы, переписки, агентные handoff-файлы.
- CONFIDENTIAL: персональные поручения, контакты, секреты, персональные материалы.
- THIRD_PARTY_RESTRICTED: чужие презентации, изображения, резюме, голоса, книги, фрагменты чат-экспортов при неустановленных правах.
- По умолчанию НЕ публиковать исходные три Telegram-архива, содержимое их чатов, APK, чужие модели/аудио и исходные PDF. Перед публикацией новых ресурсов — правовая и персональная проверка.

## Порядок принятия изменения
| Этап | Проверка | Свидетельство |
|---|---|---|
| 1. Инвентаризация | Изменённые файлы, источники и уровень доступа | diff, источник, SHA |
| 2. Требование | ID требования, измеримая приёмка | issue / PR |
| 3. Автоматика | `npm run test:static`, `npm run test:unit`, `npm run check:knowledge`, `npm run check:quality` | команда, exit code, commit |
| 4. Браузер | `npm run test:browser` в тестовой среде и моб./desktop проверка | лог, версии, при наличии screenshots |
| 5. Научная часть | Первичные источники, формулы, допущения, безопасность | действующие ACADEMY-* реестры |
| 6. Права и данные | Проверка лицензий/PII/секретов | список результатов без публикации секретов |
| 7. Публикация | Проверка развернутого URL на конкретном SHA | HTTP/smoke, дата |
| 8. Завершение | Нет обязательных FAIL/BLOCKED/NOT VERIFIED | release verdict с основаниями |

## Состояния
PASS / FAIL / PARTIAL / NOT VERIFIED / BLOCKED / NOT APPLICABLE. «Не запускалось» = NOT VERIFIED, не PASS.

## Перенос идей Synapse
Для исследования использовать структурированные карточки `IDEA`, `QUESTION`, `QUOTE`, `TASK`, `SUMMARY` и типы связей `SUPPORTS`, `REFUTES`, `SOURCE_FOR`, `DEVELOPS`. В карточке указывать исходный источник и степень проверки; автоматическое сходство не является доказательством истинности.

## Не внедрено данным PR
Полный фактчекинг Академии, запуск тестов на новых коммитах, исправление статуса источников и развёртывание Android Synapse **не выполняются только от добавления этого документа**. До фактического прохождения gate эти действия остаются открытыми.
