# Первые рабочие темы атласа

Реализованы восемь тем: GSM ткани по образцу, масса ткани по метражу, линейная плотность нити tex, длина рулона по массе и GSM, время передачи файла, размер PCM-аудио, объём древесины в брусе и расход клея.

Из соответствующих пунктов `calculator-atlas.html` ссылка «Рассчитать» открывает выбранную формулу в `calculator.html?atlasTool=<id>#labAtlasTools`. CSV отмечает эти восемь тем как работающие. Остальные 726 тем не объявлены реализованными. Существующие инструменты в других мастерских сохраняются.

Формулы приведены непосредственно у результата и следуют из перевода единиц и определений: GSM в г/м², tex в г/км, объём прямоугольного бруса, расход на площадь. Для передачи данных явно различаются МиБ и Мбит/с. PCM без сжатия, заголовков и метаданных; число отсчётов округляется вверх через точную десятичную арифметику. Все исходные данные — примеры для замены пользователем. Производственные нормы клея и свойства материала калькулятор не выдумывает.

Модуль `atlas-tools.js` загружается на странице калькуляторов только при раскрытии блока. Страница атласа использует тот же реестр для рабочих ссылок. Все расчёты выполняются локально, внешних запросов и библиотек нет. Пустые, отрицательные, бесконечные, шестнадцатеричные и другие недопустимые значения отклоняются; нулевые знаменатели блокируются. При ошибке старый числовой результат заменяется сообщением.
