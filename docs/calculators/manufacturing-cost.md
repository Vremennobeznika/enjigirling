# Стоимость изготовления и проката

Панель: `calculator.html#labManufacturing`. Собственная реализация общих формул себестоимости; код, дизайн и коэффициенты MakerRate не копируются. Тематический источник: https://makerrate.cc/ (проверен 26.10.2026). Доступны 12 названий технологий MakerRate, общий расчёт по введённым ставкам и четыре геометрии проката. Выбор технологии не вычисляет автоматически режим, время, расход материала или технологичность детали. STL/STEP/DXF не импортируются.

## Формулы и единицы

- План заготовок: `ceil(N / (1 - reject/100))`. Это план при заданной доле брака, а не гарантия выхода годных. Затраты на заготовку умножаются на план; подготовка и оснастка относятся ко всей партии.
- Материал: `заготовки × кг/заготовку × ₽/т / 1000`.
- Станок и труд: `заготовки × минуты/заготовку × ₽/час / 60`.
- Прямые затраты: материал + станок + труд + подготовка + оснастка.
- Себестоимость: прямые затраты × (1 + накладные/100).
- Цена с наценкой: себестоимость × (1 + наценка/100). Наценка не равна маржинальности.
- Цена одной годной детали: сумма по партии / N.
- Масса: плотность × площадь сечения × длина. Миллиметры переводятся в метры.
- Прямоугольная труба рассчитывается без скруглений. Для закупки применять массу сортамента/поставщика; расчёт по идеальной геометрии приблизительный.

Все расходы должны быть согласованы по включению НДС. Отдельной модели налогов, доставки и скидок нет. Не считать повторно энергию или труд, уже включённые в ставку станка. Для печати вводить расход с поддержками/технологическими потерями, для литья — расход с литниками и расходы на оснастку. Нулевые ставки — отсутствие этой статьи в расчёте, а не рыночные тарифы.

## Цены mc.ru — автоматический прайс

27.10.2026 найден рабочий официальный архив `http://mc.ru:8080/prices/metserv.zip`. Ссылка на старую версию с портом 8080 опубликована на главной странице mc.ru; ссылка на ZIP — на странице прайсов. Прямой HTTP GET архива подтвердился и в рабочей среде, и на GitHub Actions. Основной HTTPS и HTTP на стандартном порту из обеих сред не отвечали. Дополнительный официальный адрес `http://en.mc.ru/prices/metserv.zip` также отвечает, но его архив принимается только при подходящей структуре и свежих датах.

`scripts/update-mc-prices.py` извлекает четыре XLS: листовой, сортовой, качественный прокат и трубы. Начальный реальный снимок содержит 1372 ставки. Даты берутся из самих XLS: 26.10.2026, 13:08–13:46 по Москве; дата загрузки записывается отдельно. Надпись на странице прайсов «на 27.10.26» не перенесена на вчерашние XLS. НДС указан на странице прайсов как включённый во все цены.

Включены только строки с явной единицей `т`, положительной ценой, идентифицируемым разделом, описанием и размерами. Мёрджи Excel раскрываются только в отдельных колонках; соседние независимые блоки таблицы не объединяются. Строки с `теор.т`, `шт`, `м`, неоднозначным разделом или неполной идентификацией исключены. Одинаковые описания с разными ценами сохраняются отдельными вариантами с номером строки/колонки; самая дешёвая цена автоматически не выбирается. Это ограниченная выборка из общего прайса, не весь ассортимент поставщика.

В браузере по умолчанию включён mc.ru: посетитель выбирает позицию, ставка подставляется сама. Загрузка файлов и перенос цен не нужны. Снимок загружается с того же сайта только при открытии калькулятора. Внешних запросов к mc.ru или посредникам из браузера нет. Собственная ставка сохранена как отдельный необязательный режим с отключённой атрибуцией mc.ru.

Для сортового проката сохранено условие «цена от 5 т»: сумма масс плановых заготовок ниже 5 т блокирует применение этой ставки. Там, где порог не указан, интерфейс прямо об этом сообщает. Общий прайс относится к Москве, но не указывает склад, остатки и все измерения заготовки; точный склад и наличие не выдумываются. Цена служит ориентиром для расчёта по заданной пользователем массе, не подтверждением конкретного предложения на поставку.

Workflow `Update official MC prices` автоматически запускается каждые 6 часов (cron `23 */6 * * *` UTC), проверяет XLS-структуру и даты, сохраняет JSON в репозитории и публикует его в существующий Yandex Object Storage сайта. Новые секреты не нужны: используются уже настроенные `YC_S3_KEY_ID` и `YC_S3_SECRET_KEY`. После успешного обновления GitHub Pages пересобирается через `workflow_run`, поскольку push с GITHUB_TOKEN не запускает обычные push-workflows. Неуспешная загрузка/проверка не заменяет предыдущий JSON. Снимок и даты XLS старше 72 часов не применяются браузером. При ошибке пользователю показывается статус, но не предлагается вручную загружать прайс.

Архив поставщика доступен по открытому HTTP; в этом соединении не передаются учётные данные. Проверки структуры, дат и хеши помогают воспроизвести источник, но не являются криптографическим подтверждением подлинности транспорта. Файлы и оформление поставщика в сайт не встраиваются: публикуются выбранные фактические поля и ссылка на первоисточник.

`node tests/manufacturing-cost.cjs`

`python3 -m pip install 'xlrd==2.0.2' && python3 tests/mc-price-import.py`

`node tests/mc-prices.cjs`

`npx playwright test tests/manufacturing-cost.spec.cjs tests/mc-prices.spec.cjs --project=chromium-desktop --workers=2`

Проверяются распределение разовых расходов, пересчёт ₽/т, брак, наценка, четыре сечения, недопустимые входы, загрузка только при раскрытии, сохранность прежних калькуляторов и вёрстка от 320 px.
