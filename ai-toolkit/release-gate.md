## Значения статусов
- PASS — выполнено и есть доказательство.
- FAIL — выявлен дефект.
- NOT RUN — не запускалось.
- N/A — неприменимо с пояснением.
- BLOCKED — выполнить нельзя; указать препятствие.

## Правило выпуска
**GO** — все обязательные критерии PASS; неприменимые объяснены. **NO-GO** — есть критичный FAIL или BLOCKED. Наличие CI-файла не доказывает прохождение CI. Собственная проверка разработчика не считается независимой экспертизой.

## Отчёт
Указать точную версию, проведённые проверки, исправления, известные дефекты, решение GO/NO-GO и подтверждённую ссылку на результат.
