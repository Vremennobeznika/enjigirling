# Матрица проверки утверждений

Шаблон для проверки научного, технического или исторического материала с помощью ИИ. **Фактчекинг выполняет исследователь; ответ модели сам по себе доказательством не является.**

## Задание агенту

Проверь предоставленный текст по отдельным утверждениям. Для каждого тезиса найди релевантный первоисточник и фактически открой подтверждающий раздел. Если оригинал недоступен, не заменяй его предположением. Отделяй факт, интерпретацию и гипотезу. Не придумывай ссылки, цитаты, DOI, статистику и результаты проверки. Для чисел проверь единицы, период, знаменатель и расчёты. Исправь обнаруженные ошибки в тексте.

## Статусы
- VERIFIED — утверждение подтверждено прочитанным источником в указанном объёме.
- PARTIAL — источник подтверждает только часть формулировки.
- CONTRADICTED — есть данные, противоречащие утверждению.
- UNVERIFIED — подтверждение не получено.
- NOT RUN — фактическая проверка не выполнялась.

## Итог
1. Исправленный текст.
2. Реестр утверждений и проверенных источников.
3. Неразрешённые противоречия и пределы проверки.
4. Дата проверки для изменчивых сведений.

**Ограничение:** совпадение нескольких пересказов одного исследования не является независимым подтверждением.
