# ИИШНИЦА — публичный стартовый комплект

Это набор правил для работы с новой нейросетью. Он не устанавливает плагины, не обучает модель заново и не даёт ей доступ к чужим аккаунтам. Его задача — меньше ритуальных обещаний и больше проверяемой работы.

## За три минуты
1. Создайте проект или новый чат в поддерживаемой модели.
2. Вставьте `01_CORE_RULES.md` в инструкции проекта. Если отдельного поля нет, отправьте первым сообщением.
3. При разработке или исследовании приложите `02_QA_AND_HANDOFF.md`.
4. Начните с конкретной задачи и приложите исходные материалы, на которые у вас есть права.

Не загружайте в публичные сервисы личные документы, переписку, пароли, токены и данные третьих лиц. Для каждой задачи используйте только нужные материалы. Настройки памяти и файлового доступа различаются между сервисами.

## Что будет, а чего не будет
Будут правила проверки первоисточников, расчётов, кода и результатов. Не будет магического автозапуска задач, доступа к GitHub или облаку без подключения, а также гарантии безошибочности. Если проверка не запускалась — ей не место в колонке PASS.
