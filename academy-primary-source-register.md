# Реестр первоисточников и предметной аттестации инженерной академии

Дата: 2026-11-21. Статус: **НЕ АТТЕСТОВАНО**. Все 49 уроков перечислены ниже. Наличие ссылки в строке означает **подобранный релевантный первоисточник**, а не подтверждение всех утверждений урока. Некоторые стандарты платные, и просмотр карточки стандарта не эквивалентен изучению его полного текста.

## Выявленные риски

1. IEC 61131-3:2013 заменён действующей IEC 61131-3:2025. Для ПЛК использовать актуальную редакцию.
2. ISO 9001:2015 заменён ISO 9001:2026. Устаревшую редакцию не объявлять действующей.
3. ISO 21920-2:2021 и ISO 21920-3:2021 — действующие опубликованные документы; проекты ISO/CD 21920-2 и -3 2026 года не являются действующими стандартами.
4. Погонная энергия сварки требует деления энергии на длину шва; в M08 рассматривается только электрическая мощность и энергия. Название исправлено.
5. Отсутствует независимая построчная проверка инженерных объяснений и практических ограничений каждого урока.

## Повторная предметная проверка — 22.11.2026

**A09, Modbus — PASS для перечисленных учебных утверждений, но НЕ общий выпускной PASS.**
Сверены непосредственно с полным текстом *MODBUS Application Protocol Specification V1.1b3* (Modbus Organization, 26.04.2012):
- § 4.2, стр. 5: для 16-битного регистра старший байт передаётся первым. Не следует из этого делать вывод о порядке слов в 32-битных значениях конкретного устройства.
- § 4.4, стр. 7–8: адрес PDU = номер элемента модели − 1; 16 → 15 и 108 → 107 (0x006B). Отображение адреса на приложение зависит от устройства.
- § 6.3, стр. 15–16: функция 03 читает holding-регистры; допустимое количество 1–125; ответ содержит два байта на регистр. Для пяти регистров поле Byte count = 10.
- Текст урока `academy-draft-part3.html#A09` соответствует этим узким положениям; обе учебные задачи проверены независимым расчётом. Реальные адреса, права доступа, безопасное подключение и аппаратные испытания НЕ подтверждены.

**A07, PLC — PARTIAL.** Карточка IEC 61131-3:2025 подтверждает действующую редакцию и область документа (ST, LD, FBD, SFC), но полный платный текст не изучен. Поэтому модель конечного автомата из урока нельзя объявить построчно подтверждённой стандартом.

**E01 и другие уроки по СИ — PARTIAL.** Официальная BIPM SI Brochure, 9-е издание, редакция июня 2026, существует; сверка конкретных утверждений и примеров каждого урока ещё требуется. Ссылка на обложку/аннотацию сама по себе не доказательство.

Остальные строки ниже сохраняют статус без аттестации. Выпускной шлюз остаётся закрыт, пока не проверены все 49 уроков и все критерии релиза.

## Подтверждение A09 по полному первоисточнику

Открыт [MODBUS APPLICATION PROTOCOL SPECIFICATION V1.1b3 (PDF, 26.04.2012)](https://www.modbus.org/file/secure/modbusprotocolspecification.pdf):
- §4.2, стр. 5: внутри передаваемого 16-битного регистра применяется big-endian (старший байт первым).
- §4.3, стр. 6: Input Registers и Holding Registers — 16-битные слова. Поэтому два регистра = 32 бита = 4 байта; три регистра = 48 бит = 6 байт.
- §4.4, стр. 7–8: в PDU адреса 0–65535, номера элементов модели 1–n; номер X отображается в адрес X−1. Привязка к устройству зависит от производителя.
- §4.1, стр. 4–5: длина полезных данных не равна длине полного сообщения.
- §6.3, стр. 15: функция 03 читает holding-регистры, допустимое количество 1–125; ответ содержит поле Byte count, равное двум байтам на регистр.

**Исправление:** в A09 заменена неверно обобщённая формулировка о «порядке байтов, определяемом устройством». Для двухбайтового регистра порядок фиксирован протоколом; для многорегистровых значений требуется карта изготовителя. После повторного QA упражнения A09 переписаны: порядковый номер элемента 16 → PDU-адрес 15 (§4.4); пять регистров → поле Byte count = 10 байт (§6.3). Эти конкретные ответы и свойства подтверждены источником; работа с реальной картой регистров и остальная предметная аттестация A09 ещё не выполнены. Это не подтверждение остальных 48 уроков.

## Проверка E01 и E05 по полному тексту BIPM

Источник: [BIPM, SI Brochure, 9th edition, version 4.01 (2026), полный PDF](https://www.bipm.org/documents/d/guest/si-brochure-9-en-pdf), §3, таблица 7, стр. 138 PDF (печатная стр. 138; PDF индекс 27): **kilo = 10³**, **milli = 10⁻³**. Примеры: E01 2,5 А × 1000 = 2500 мА; 4700 Ом / 1000 = 4,7 кОм. E05 1,25 В × 1000 = 1250 мВ; 750 мВ / 1000 = 0,75 В. Единицы и арифметика подтверждены. Предупреждения о безопасном выборе мультиметра требуют отдельного руководства изготовителя и не подтверждаются BIPM.
