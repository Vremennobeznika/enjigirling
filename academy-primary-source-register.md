# Реестр первоисточников и предметной аттестации инженерной академии

Дата: 2026-11-21. Статус: **НЕ АТТЕСТОВАНО**. Все 49 уроков перечислены ниже. Наличие ссылки в строке означает **подобранный релевантный первоисточник**, а не подтверждение всех утверждений урока. Некоторые стандарты платные, и просмотр карточки стандарта не эквивалентен изучению его полного текста.

## Выявленные риски

1. IEC 61131-3:2013 заменён действующей IEC 61131-3:2025. Для ПЛК использовать актуальную редакцию.
2. ISO 9001:2015 заменён ISO 9001:2026. Устаревшую редакцию не объявлять действующей.
3. ISO 21920-2:2021 и ISO 21920-3:2021 — действующие опубликованные документы; проекты ISO/CD 21920-2 и -3 2026 года не являются действующими стандартами.
4. Погонная энергия сварки требует деления энергии на длину шва; в M08 рассматривается только электрическая мощность и энергия. Название исправлено.
5. Отсутствует независимая построчная проверка инженерных объяснений и практических ограничений каждого урока.

## Обязательные поля закрытия каждой строки

- Точное утверждение урока, цитата/раздел действующего первоисточника, версия и дата.
- Результат проверки формулы и размерности, расчёт обоих заданий, область применимости.
- Проверка корректности предупреждений по безопасности и недопустимых интерпретаций.
- Статус PASS только после реального чтения соответствующего раздела, а не только карточки стандарта.
- Ссылка на проверяющий тест и коммит исправления.

**Выпуск запрещён до закрытия всех строк.** Текущий файл — реестр кандидатов на источники, а не сертификат соответствия.

## Проверка ссылок 2026-11-21

Открыты непосредственно:
- https://www.iso.org/standard/9001 — официальная карточка ISO 9001:2026; прежняя ссылка /standard/62085.html ведёт к **отозванной** редакции ISO 9001:2015, исправлено в уроках и реестре.
- https://webstore.iec.ch/en/publication/68533 — IEC 61131-3:2025, действующая карточка, полный текст платный.
- https://www.iso.org/standard/66777.html — ISO 1101:2017, относится к геометрическим допускам. **Не является достаточным первоисточником** для уроков C01 (масштаб), C05 (размерная цепь), E09 (предельные отклонения), C04 (посадки), C08 (общая читаемость чертежа). В этих строках источник только кандидат, требуется замена профильными документами.
- ISO 9001 задаёт требования к системе менеджмента качества, а не конкретные режимы термообработки и температурные характеристики полимеров. Для M03 и M04 ссылка на ISO 9001 недостаточна; необходимы материаловедческие первоисточники.
- BIPM SI определяет единицы и их преобразования, но не подтверждает самостоятельно закон Ома, модель RC-цепи, физику сварки или расчёт массы по плотности. Для E03, E06, M08, M10 требуются профильные источники.

**Вывод:** аттестация по фактически прочитанным источникам не может быть закрыта. Подстановка ссылки вместо подтверждения конкретного утверждения запрещена.

## Прямое чтение первичных страниц (2026-11-21)

- [BIPM SI Brochure, 9th ed.](https://www.bipm.org/en/si-brochure-9): открыта официальная страница; версия 4.01 пересмотрена в июне 2026. Страница подтверждает существование документа, но не доказывает формулы электротехники.
- [Modbus Organization](https://www.modbus.org/modbus-specifications): открыта официальная страница; Modbus Application Protocol Specification V1.1b3 перечислена как первичный документ. Содержание регистров A09 требует чтения самого PDF.
- [IEC 61131-3:2025](https://webstore.iec.ch/en/publication/68533): открыта официальная карточка. Предмет документа — синтаксис и семантика языков ПЛК; он **не является** первоисточником для определения ошибки регулирования A01 или масштабирования 4–20 мА A04. Полный текст платный; карточка не заменяет его.

Решение по предметным строкам: E01/E05 — допустимо проверять приставки СИ по BIPM после сверки соответствующего раздела; A09 — читать PDF Modbus; A01/A04 — заменить нерелевантную ссылку IEC 61131-3 на профильный первоисточник. Ни одна строка не переведена в PASS без полной проверки.
