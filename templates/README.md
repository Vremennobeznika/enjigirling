# Шаблоны инженерной проверки

Два CSV-файла, кодировка UTF-8 с BOM, разделитель — точка с запятой. Их можно открыть в Excel, LibreOffice Calc или импортировать в учётную систему. **Это пустые рабочие формы, а не утверждённые стандарты**.

## [Карта анализа дефектов](production-defect-review.csv)

1. Идентифицируйте конкретную партию, операцию и обнаруженный признак без преждевременного вывода о причине.
2. Зафиксируйте метод выявления, объём проверки и число несоответствий. Ноль и отсутствие данных — разные состояния.
3. Отдельно запишите гипотезу причины и свидетельства, которыми её проверяли.
4. Для действий назначьте владельца, контрольный срок и критерий закрытия; ссылку на применимый нормативный документ указывайте только после проверки редакции.

## [Реестр свойств материалов](material-evidence-register.csv)

1. Одна строка — **одно свойство одной марки материала в указанных условиях**. Не объединяйте свойства разных марок, состояний поставки или температур.
2. Указывайте значение вместе с единицей, методикой измерения, редакцией применимого документа и ссылкой на первоисточник.
3. Не подставляйте типичные или справочные величины в качестве гарантированных свойств партии.
4. Возможные статусы: «не проверено», «источник найден», «число сверено с источником», «проверено для партии». Последний статус требует документов именно на соответствующую партию.

Шаблоны не заменяют систему управления качеством, производственную документацию или требования заказчика. Редакционный проект [ENJIGIRLING](../index.html).
