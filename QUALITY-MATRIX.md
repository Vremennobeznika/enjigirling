## Единый запуск

```sh
node scripts/all-checks.cjs
node scripts/check-live-site.cjs  # только для опубликованного сайта, требует сети
npm install
npx playwright install chromium
npx playwright test
```

Первые команды выполняют статическую проверку и валидацию JSON, последняя — браузерные сценарии. Проверка фактов, промышленной безопасности, контраста, производительности и реального деплоя требует отдельных свидетельств. **Нельзя отмечать их PASS без фактического прогона.**

## Правила выпуска

- P0 FAIL: не публиковать.
- P0 REVIEW: публиковать только с явной оговоркой об ограничениях; инженерные цифры не объявлять проверенными.
- P1 FAIL: фиксировать дефект и исправлять до следующего релиза.
- Для каждого исправления сохранять ссылку на коммит и повторять матрицу.

## Дополнительная регрессия девяти разделов

`tests/all-sections.spec.cjs` обходит все девять страниц на desktop: проверяет `main`, девять ссылок навигации, горизонтальный overflow, ошибки JavaScript, HTTP-ошибки локальных ресурсов и переходы по всем разделам. Подхватывается существующей командой `npx playwright test` в обоих workflow. До фактического прогона статус сценария — NOT RUN.

## Машиночитаемый единый вход

`knowledge/ai-context.md` содержит каталог всех индексированных записей с прямыми URL на исходные страницы. Файл генерируется `scripts/build-knowledge.cjs`, поэтому проверяется на точное совпадение в `--check`. Публикационный HTTP smoke также проверяет его присутствие. Это редакционные описания, а не технически аттестованные первоисточники.

## Контроль достоверности набора для ИИ

- `knowledge/quality.json` — воспроизводимый сводный отчёт по четырём наборам: количество записей, привязок и заявленных проверок утверждений.
- `node scripts/build-quality.cjs --check` — проверка точного совпадения отчёта с реестром и каталогом (включена в `all-checks.cjs`).
- `tests/full-matrix.cjs` независимо сверяет число связанных карточек, уникальных первоисточников и статус `metadata_integrity_only`.
- `scripts/check-live-site.cjs` после публикации сверяет SHA-256 отчёта и число записей с поисковым индексом.
- **Запрещено** считать статус `source_located` эквивалентом проверки утверждения. Аудит содержательной точности остаётся `REVIEW`.
