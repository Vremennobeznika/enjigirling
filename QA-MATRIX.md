## Обязательные условия выпуска

1. **Блокирующие:** P01–P06, D01–D09, A01–A03, S03, C01–C05. Блокирующая ошибка не должна оставаться незамеченной.
2. **Отдельная предметная приемка:** P11, F05–F09, D10–D12, S01–S02 требуют независимых измерений или проверки документов. Не маркировать их PASS по результату статических тестов.
3. **Никаких ложных «проверено»:** 5 найденных источников и 7 ссылок на записи из 626 — это обнаруженные источники, а не подтверждение всех утверждений.
4. Изменения в девяти существующих разделах требуют повторного Playwright-прогона на мобильном и десктопном разрешениях.
5. Публикация считается подтвержденной только после успешного workflow и запроса к реальному адресу Pages.

## Текущий результат первичного прохода

Проверены исходники девяти HTML-страниц через GitHub Contents API: у всех 9 есть `title`, один `main`, девять навигационных вкладок и нет повторяющихся HTML-`id`. В JSON-индексе 626 записей, граф содержит 61 связь; в реестре 5 источников и 7 привязок. Полный CI/Playwright и публичный HTTP-деплой ещё не подтверждены. Статусы PENDING должны обновляться по итогам нового автоматического теста, не заранее.

## Дополнительная сверка после записи матрицы

- Взяты из актуальной ветки репозитория четыре JSON-набора, поисковый индекс и граф: 51 профессия, 12 материалов, 12 процессов, 551 термин; всего 626 индексных записей.
- Нормализованные идентификаторы внутри наборов уникальны; дубли идентификаторов поискового индекса не обнаружены.
- Все концы 61 ребра графа входят в набор из 75 известных узлов. Ошибок связности этого типа не найдено.
- `tests/full-matrix.cjs` включён в `scripts/all-checks.cjs`, используемый обеими GitHub Actions workflows. Факт выполнения workflow и состояние публичного URL пока НЕ подтверждены.
