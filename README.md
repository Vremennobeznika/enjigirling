# enjigirling

База данных по профессиям инженеров: статистика, обучение, зарплаты, карьерный рост.

Статический каталог инженерных профессий с модальными карточками, зарплатами по
федеральным округам, карьерным ростом, типичным днём, плюсами и минусами,
календарём инженерных праздников, словарём терминов, картой обучения и
инженерными калькуляторами.

## Разделы сайта

- **Профессии** — каталог инженерных специальностей с фильтрацией по разделам,
  поиском, сортировкой и подробными карточками.
- **Календарь праздников** — профессиональные и инженерные праздники по месяцам
  с поиском и фильтрацией по профессиям.
- **Ресурсы сообщества** — журналы, форумы, платформы для разработок и Telegram-чаты
  для инженеров.
- **Словарь инженера** — термины, сокращения и понятия из инженерных и технических
  областей с поиском.
- **Карта обучения** — интерактивная карта федеральных округов: ведущие инженерные
  вузы и техникумы, льготы и олимпиады при поступлении, курсы и онлайн-обучение.
- **Калькуляторы** — на странице «Обучение»: «Сколько учиться до первой зарплаты», зарплата по
  профессии и региону, зарплата на руки (НДФЛ 2026), окупаемость обучения; на странице
  «Калькуляторы инженера»: конвертер единиц, системы счисления, токовый сигнал 4–20 мА.

## Структура проекта

- `data.js` — данные о профессиях
- `script.js` — логика каталога профессий
- `resources-data.js` — данные о ресурсах сообщества
- `resources.js` — логика раздела ресурсов
- `dictionary-data.js` — данные словаря инженера
- `dictionary.js` — логика словаря
- `map-data.js` — данные карты обучения (вузы и техникумы)
- `map.js` — логика карты обучения
- `map-calc.js` — калькулятор «Сколько учиться до первой зарплаты»
- `engineer-calculators.js` — зарплата по региону и на руки (НДФЛ), окупаемость обучения, конвертер единиц,
  системы счисления, сигнал 4–20 мА
- `theme.js` — переключение темы (эмодзи 🌙 / ☀️), выбор запоминается в `localStorage`
- `style.css` — стили сайта
- `index.html`, `calendar.html`, `resources.html`, `dictionary.html`, `map.html`, `calculator.html` — страницы

## Как добавить профессию

1. Добавьте запись в `data.js`: скопируйте любую соседнюю и поменяйте поля.
2. Впишите её `id` в нужный раздел в начале `script.js` (`CATEGORY_PROFESSIONS`).
3. Для профессий раздела «АСУ ТП» кнопка во второй строке фильтра появится сама.
4. Если у профессии есть профессиональный праздник, добавьте её `id` к событию в `calendar.html`.

## Шрифт и размеры текста

- Шрифт на всём сайте один — Inter (подключается в начале `style.css`, задан переменной `--font`).
- Размеры берутся из шкалы `--fs-xs` (12 px), `--fs-sm` (14), `--fs-md` (16), `--fs-lg` (18), `--fs-xl` (20),
  `--fs-2xl` (24), `--fs-3xl` (32); заголовки страниц — `--fs-h1` и `--fs-h2`. Начертания: 400, 600, 700.
- Новый текст стилизуйте этими переменными, а не числами в пикселях.

## Достоверность данных

**Важно:** количественные сведения о числе специалистов, среднем возрасте, гендерном составе и зарплатах в `data.js` пока не имеют подтверждённых первичных источников, единой методики и даты актуализации. Их нельзя цитировать как официальную статистику или использовать для кадровых, финансовых и образовательных решений без независимой проверки.

Калькулятор зарплат по регионам использует эти ориентировочные записи. Калькулятор НДФЛ оценивает среднемесячную сумму при постоянном доходе в течение 12 месяцев и не заменяет расчёт работодателя. Калькулятор окупаемости обучения не учитывает упущенный заработок во время учёбы, инфляцию и налоги.

Перед публикацией подтверждённой статистики для каждой записи нужны: URL первоисточника, дата публикации/сбора, определение показателя, география и методика расчёта. Пока этих данных нет, значения должны оставаться явно помеченными как непроверенные.

## Автоматические проверки

GitHub Actions запускает `node --check` для JavaScript-файлов и `node tests/site-check.cjs` для локальных HTML-ссылок, структуры профессий, проверки числового ввода и предупреждений о качестве данных.

## Реестр источников зарплат

`salary-sources.js` содержит запись для каждой из 51 профессии. Для 15 профессий найдены конкретные страницы hh Карьера с опубликованными зарплатными диапазонами (срез 20 октября 2026 года, регион страницы — Москва). Для остальных 36 записей статус `unverified`. Ссылки и числовые значения из реестра отображаются отдельно от ранее внесённых оценок в карточках профессий и калькуляторе.

**Ограничения:** диапазоны hh Карьера не следует выдавать за медианную зарплату всей профессии по России, а тем более переносить их на федеральные округа. Сайт источника динамический; для сопоставления с другой датой нужно повторно проверить диапазон, регион, стаж и состав выборки. Название профессии в источнике может быть шире, чем специализация в каталоге (например, инженер-проектировщик вообще и инженер-проектировщик ПГС). Источники для 36 профессий остаются открытой задачей.
