# ENJIGIRLING — инженерный справочник

Сайт: https://vremennobeznika.github.io/enjigirling/

Открытый статический справочник: **51 инженерная профессия, 9 разделов**. Содержит описания задач, направления подготовки, карьерные роли, каталог процессов и материалов, календарь инженерных праздников, словарь, ресурсы сообщества, сведения об обучении и инженерные калькуляторы.

## Разделы

1. [Профессии](index.html) — поиск, сортировка, категории, 51 подробная карточка.
2. [Календарь](calendar.html) — профессиональные даты.
3. [Ресурсы сообщества](resources.html) — ссылки и фильтры.
4. [Словарь](dictionary.html) — термины и поиск.
5. [Обучение](map.html) — карта, образовательные направления и калькуляторы.
6. [Калькуляторы](calculator.html) — единицы измерения, системы счисления, сигнал 4–20 мА.
7. [Сравнение](compare.html) — сопоставление инженерных профессий.
8. [Процессы](processes.html) — обзор производственных процессов.
9. [Материалы](materials.html) — обзор инженерных материалов.

## Достоверность сведений (проверено 20 октября 2026)

- `data.js`: 51 профессия. **Удалены** неподтверждённые данные о численности, возрасте, гендерном составе, универсальных сроках обучения, карьерных сроках и суммах зарплат. Описательные поля — редакционные, а не официальные требования работодателя.
- `salary-sources.js`: 51 запись, **50 опубликованных числовых ориентиров и 1 без подтверждённой суммы**. По типу подтверждения: 41 запись отмечена как проверенная страница, 8 относятся к смежным должностям, 1 к вакансии работодателя, 1 не подтверждена. «Проверена страница» означает только сверку содержимого на определённую дату, а не репрезентативность, точное соответствие профессии или юридическое подтверждение. **По восьми смежным профессиям суммы не переносятся на основные карточки.**
- Исходная ссылка на вакансию АВТОВАЗа стала отвечать HTTP 404; её зарплата скрыта, вместо неё оставлена только поисковая ссылка на вакансии для самостоятельной проверки. Одна вакансия не доказывает среднерыночную зарплату.
- Зарплатный блок в разделе «Обучение» показывает **сведения по источнику, без выдуманной разбивки по федеральным округам**. Для непроверенных и смежных источников конкретная оценка скрыта.
- Кандидаты профстандартов приведены для 7 из 51 профессии. Их действующие редакции, сопоставление конкретным трудовым функциям и обязательность применения **ещё не подтверждены**. Отсутствие документа в карточке не доказывает отсутствие профстандарта.
- Образовательные программы и профессиональные требования для всех 51 позиций требуют отдельной сверки с официальными учебными планами и реестрами.

## Автоматические проверки

GitHub Actions:
- **Static QA**: `node scripts/all-checks.cjs` в сборке публикации и проверках PR — ссылки на локальные ресурсы, 51 профессию, данные, инженерные связи и качество источников.
- **Playwright на публикации**: `npx playwright test` — адаптивная вёрстка, доступность, карточки профессий, общий поиск, калькуляторы, данные и переходы. Набор расширяется; не привязан к старому количеству 35 тестов.
- **External link audit**: `tests/external-links.cjs` — реальные HTTP-проверки сайтов, зарплатных источников и нормативных ссылок. Контрольный запуск: **144 URL; 118 доступны, 0 подтверждённых ошибок HTTP 404/410, 26 не подтверждены** (включая блокировки и сетевые ошибки). Недоступность для бота не равна удалению страницы.
- **Salary evidence content audit**: `tests/salary-source-content.cjs` — повторяемая проверка наличия числовых строк на страницах зарплатных источников; даже совпавшие числа не доказывают качество выборки или соответствие должности.
- **GitHub Pages**: сборка и публикация статического сайта.

## Как добавить профессию

1. Создать новую запись с уникальным `id` в `data.js` и привязать его к категории в `script.js`.
2. Добавить отдельную запись в `salary-sources.js`, указать реальные данные, ссылку, дату, методику и честный уровень достоверности. Непроверенные суммы оставлять `null`, а запись — `unverified`.
3. Профстандарты искать по **трудовым функциям**, проверять действующую редакцию и юридическую применимость; не подбирать по одному названию.
4. Запустить автоматические и браузерные тесты и обновить матрицу.

**Ограничение:** успешные проверки функциональности не подтверждают научную, правовую или статистическую достоверность описаний. Для полного закрытия предметного аудита нужны проверяемые нормативные документы, конкретные учебные программы и корректные зарплатные выборки для каждой профессии.

### Обновление данных и контроль качества

```bash
npm install
npm run build:knowledge
npm run check:knowledge
npm run test:unit
npx playwright install chromium
npm run test:browser
```

JSON-экспорт строится из существующих JavaScript-каталогов. При публикации через workflow `.github/workflows/knowledge-pages.yml` файлы пересоздаются перед развёртыванием. `.github/workflows/site-check.yml` проверяет Pull Request и допускает ручной запуск; основной запуск на `main` выполняет `.github/workflows/knowledge-pages.yml` с браузерной и статической проверкой до деплоя. Если меняете исходные каталоги, пересобирайте JSON тем же коммитом, чтобы контроль синхронизации проходил.

Публикация через Actions требует настройки GitHub Pages в разделе **Settings → Pages → Source: GitHub Actions**. Успешный запуск и доступность опубликованного URL проверяются отдельно.

## Новые калькуляторы, экономия трафика

Раздел [«Калькуляторы»](calculator.html) включает базовые преобразования единиц, системы счисления и 4–20 мА, а также шесть дополнительных инструментов в двух сворачиваемых панелях:

- IEEE‑754: **FP16, bfloat16, TF32, FP32, FP64**, десятичное число ↔ HEX/битовая строка, изменение отдельного бита, знак/порядок/мантисса, точная ошибка двоичного представления относительно введённой десятичной строки;
- закон Ома и мощность (DC);
- делитель напряжения без нагрузки;
- RC-время и частота среза идеальной цепи;
- допусковая цепь размеров: худший случай и RSS;
- декодирование Float32 из двух 16-битных Modbus-регистров для четырёх порядков байтов.

**Оптимизация:** страница калькуляторов больше не загружает data.js и salary-sources.js (вместе около 82 КБ исходного текста); новые вычислительные модули engineering-lab-core.js и engineering-lab-ui.js подгружаются лишь при первом раскрытии. Нет внешних математических библиотек, сетевых запросов или анимации вычислений. Промежуточные данные не отправляются на сервер.

Точность: FP32 и FP64 используют DataView; 16- и 19-битные форматы реализованы с округлением к ближайшему, при равенстве — к чётному. **TF32 представлен логическими 19 битами**, это не 32-битное машинное слово; 32-битное кодирование конкретного ускорителя следует смотреть в его документации. Ограничения схем и статистической модели RSS указаны непосредственно в интерфейсе.

Автоматическая проверка: node tests/engineering-lab-unit.cjs, npx playwright test tests/engineering-lab.spec.cjs.

Исходный пример для изучения интерфейса: [Float Converter](https://flop.evanau.dev/) — реализована собственная логика и оформление, без копирования кода или ассетов чужого сайта.
