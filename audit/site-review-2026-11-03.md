## Что изменено

1. Сохранены актуальная автоматизация MC и обновления бота, появившиеся после прошлой проверки. Прежний вывод «автопрайс не подключён» к текущему main не относится.
2. На новую базу перенесены ранее не опубликованные исправления проверки обучения: выведены из активной карточки две страницы с 404, снято неподтверждённое основание программы, дата проверки берётся из данных, все 80 организаций попадают в аудит URL. Изменения не выдаются за восстановление внешних документов.
3. В штатную диагностику добавлено только чтение безопасных метаданных хостинга, без публикации секретов и без изменения политик.
4. Добавлены `scripts/check-public-access.py` и регрессионный тест. Русский выпуск и обновление MC после подписанной проверки должны пройти ещё и анонимный HTTP-контроль; закрытая публикация больше не считается успешной только по signed S3 GET.
5. В проверщик ссылок добавлен режим повторения только `unverified` из указанного JSON и соответствующий ручной вход workflow. В отчёте явно фиксируется область проверки, чтобы подмножество не выдавалось за весь инвентарь.

## Блокировка восстановления

Подготовлена узкая попытка добавить anonymous READ к публичной index.html с сохранением всех существующих ACL-грантов. Автоматическая проверка разрешений отклонила запуск: изменение ACL — постоянное изменение настройки безопасности, не покрытое явным одобрением пользователя. **Ни одна ACL или политика бакета не изменена.** Отказ не обходился другой командой, политикой бакета или деплоем с расширением разрешений.

Для согласования подготовлен `/workspace/hosting-public-files-approval.json`: точные 154 пути текущего публичного дистрибутива, их SHA-256 и единственное предлагаемое право `AllUsers: READ`. Остальные объекты, листинг бакета, запись и удаление в план не входят; существующие гранты должны сохраняться. Это откроет перечисленные материалы всем посетителям. Текущему CI-ключу дополнительно требуется работоспособная запись объектов: одного анонимного чтения недостаточно для последующих обновлений прайса. Возможность исправить это имеющимся ключом не установлена.
