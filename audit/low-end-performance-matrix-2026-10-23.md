# Матрица оптимизации для слабых устройств — 2026-10-23

## Подтверждённые изменения
- Главная страница более не подключает материалы, процессы и словарь при обычном открытии: удалены три начальных запроса к `materials-data.js` (276648 Б), `processes-data.js` (331960 Б) и `dictionary-data.js` (113887 Б). Итого 722495 Б / около 706 КиБ *исходных* файлов, не байтов сжатой сети.
- При первом запросе в общем поиске файлы загружаются параллельно; индекс создаётся однократно. Следующие запросы используют память, а ошибку загрузки можно повторить.
- Новая проверка `tests/performance-budget.cjs` контролирует необработанный начальный HTML+локальные CSS/JS, отсутствие дубликатов и лимит 1100 КиБ по 13 маршрутам (если они присутствуют).
- Добавлен `tests/global-search-lazy.spec.cjs`, проверяющий отсутствие исходных каталогов до поиска, результаты по материалам, однократную загрузку и повтор после сетевой ошибки.
- Бюджет включён в `scripts/all-checks.cjs`.

## Границы подтверждения
Структура файлов исследована через GitHub API, исходные размеры взяты из Git tree. Файлы изменений повторно прочитаны из `main`. Новые проверки добавлены, но фактический прогон CI, Lighthouse и реальных слабых устройств **не подтверждён**. Следовательно, заявлять измеренный прирост Lighthouse, экономию переданных по сети байтов, выполненную CPU/память оптимизацию либо прохождение всех тестов нельзя.

## Дальнейшие ограничения
Не минифицировать слепо несвязанные каталоги, не ломать экспорт ИИ и не удалять редакционные данные ради размера. Следующий этап должен основываться на отчётах браузерного тестирования по маршрутам.
