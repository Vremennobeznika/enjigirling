## Полнота
Все семь URL получили проверяемое редакционное решение: два перенаправления/замены назначения, один новый живой форум, три сохранённых исходных ресурса с ограничениями доступа и две исторические вакансии с исключёнными зарплатами (категории перекрываются по типу действия). Принципиально невозможная без реального доступа вещь — **доказать, что защищённые сайты откроются для каждого читателя**. Такого заявления не делаем.

CI: статическая матрица, браузерная регрессия, ресурсный каталог, персональные данные и опубликованные файлы проверяются GitHub Actions после этого коммита.
