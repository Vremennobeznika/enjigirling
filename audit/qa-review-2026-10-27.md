## Найденное и исправленное

1. **P1, ложный отказ проверки выпуска.** Верификатор GitHub Pages требовал self-canonical у старого `calculator-atlas.html`. Страница намеренно направляет на объединённый `calculator.html` и правильно имеет его canonical. Исправлен контракт проверяющего скрипта; canonical страницы не испорчен ради зелёного теста. Исправленный smoke реально прошёл на опубликованной версии. Добавлена проверка лениво загружаемых MC JS-файлов и валидация актуального JSON без требования побайтового совпадения независимо обновляемого прайса.
2. **P2, невоспроизводимая установка.** В репозитории отсутствовал package-lock.json, npm ci в корректном каталоге завершался ошибкой. Добавлен lock-файл для имеющихся зависимостей; чистая установка прошла. Девять корневых CI-workflows переведены с npm install на npm ci. Runtime-зависимости сайта не добавлялись.
3. **P2, два официальных URL стали 404.** У Тюменского техникума действующие страницы перенесены с `/enrollees/` на `/enrolles/`. Найдены ссылки в текущем меню того же учреждения, получены HTTP 200, прочитаны страницы «Правила приема» и «Контрольные цифры приема», проверено присутствие программы 08.02.01. Заменены оба URL, обновлена дата HTTP-сверки конкретной записи и пересобраны экспорты. Учреждение и числа не подменены, общий портал не назван восстановлением конкретного документа.
4. **P2, стенды личного приложения устарели.** Два inline-стенда не подключали goals.js, из-за чего init попадал в восстановительный экран, а тесты ошибочно сообщали о сломанном пользовательском потоке. Исправлены состав и порядок модулей; русскому стенду явно задан ru-RU. Повтор: 115 и 80 PASS.
5. **P2, тесты запрещали корректное изменение окружения и дат.** Everyday считал любой порт кроме 8765 внешней передачей данных; тест теперь сравнивает origin с настроенным baseURL. Проверка образовательного каталога требовала ровно 22.10.2026 для каждого HTTP-наблюдения; теперь проверяет допустимую календарную дату и границы, не вынуждая сохранять ложную старую дату.
6. Ранее подготовленные карточки Mini QR и NGINX Config включены в проверенную подборку ресурсов. Это ссылки с собственными описаниями; код и изображения этих проектов не встраивались. Предыдущий незакрытый аудит зависимостей возможного будущего встраивания не объявлен завершённым этой проверкой.
