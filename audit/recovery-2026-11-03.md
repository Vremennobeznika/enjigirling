- PR #41 объединён после успешных проверок. Исправления прежнего аудита обучения перенесены на актуальный main с сохранением автоматизации MC.

- Постоянное право CI на запись main не добавлялось. Вариант с новым автоматическим писателем был отклонён автоматической проверкой разрешений и заменён обычным включением проверенных файлов в PR. Workflow проверяет актуальность этих файлов и использует уже настроенный режим Pages.

- После загрузки файлов добавлена проверка анонимного доступа; подписанное чтение из S3 не выдаётся за доступность для посетителей.

## Что требуется от владельца Yandex Cloud

Восстановить для сервисного аккаунта, чьи ключи используются в `YC_S3_KEY_ID` / `YC_S3_SECRET_KEY`, возможность выполнять **GetObject, PutObject, GetObjectAcl и PutObjectAcl** над публичными файлами бакета `enjigirling.ru`. Проверить мешающие политики/ограничения аккаунта, если эти права уже назначены. Значения ключей в чат передавать не нужно.

После восстановления прав можно применить согласованный READ только к 154 файлам из `/workspace/hosting-public-files-approval.json`, сохранив остальные гранты, и повторить публикацию/анонимный HTTPS-контроль. Это не разрешение раскрывать остальные объекты, включать листинг, изменять DNS или выдавать всем запись.

**Вердикт:** зеркало восстановлено и проверено. Основной домен не готов до исправления доступа владельцем Yandex Cloud. Сетевые ограничения 76 сторонних источников не скрыты и не устранены вымышленной заменой URL.
