# ENJIGIRLING — акт технической проверки, 24.10.2026

**Объект:** https://github.com/Vremennobeznika/enjigirling — девять основных разделов публичного сайта.  
**Основание:** замечания пользователей по карточкам профессий, контрольный файл «БП», запрос на проверку сайта и GitHub Actions.  
**Принцип:** различать исходные сведения, структуру, подтверждение источников, браузерную проверку и проверку опубликованной версии.

## Область и метод

- Девять основных разделов: профессии, календарь, ресурсы, словарь, обучение, калькуляторы, сравнение, процессы, материалы. Статическая проверка охватывает 13 корневых HTML-файлов и 300 ссылок на локальные ресурсы.
- 51 карточка профессий, 172 материала, 208 процессов, 80 образовательных записей, 175 инженерных ресурсов. Контроль уникальности и перекрёстных ссылок выполнялся средствами GitHub Actions.
- Браузер: автоматизированный Playwright/Chromium, в том числе контроль интерфейса на ширинах 320, 375, 390, 768 и 1440 пикселей, две темы. Это не проверка на реальном маломощном Android.
- Доступность и производительность: лабораторный Lighthouse по девяти страницам. Контроль цвета текста внутри модального окна — автоматический расчёт контрастности, не экспертный полный WCAG-аудит.
- Ссылки: GET-запросы с различением успешного ответа, подтверждённых 404/410 и неустановленного статуса (ошибка сети, ограничение доступа, иной HTTP-код). Успешный HTTP-код сам по себе не доказывает актуальность содержания.

## Неустранённые ограничения и риски

- Отчёт качества базы знаний указывает для 51 профессии **0 source-located / 0 claim-checked** в структуре привязки отдельных утверждений. Наличие справочного перечня профстандартов не равнозначно проверке всех описаний и их обязательности.
- Отдельные внешние URLs остались **неверифицированными** из-за недоступности сервера, блокировки или неоднозначного HTTP-ответа. Нельзя маркировать их как рабочие или сломанные без дополнительной проверки.
- Нет испытания производительности и поведения на настоящем слабом Android-устройстве; успешные тесты Chromium не означают отсутствие зависаний в любой среде.
- Значения Lighthouse, проанализированные до последующих коммитов, — отдельный лабораторный замер, а не подтверждение прироста скорости.
- Доступность Lighthouse 100/100 не исключает проблем, не обнаруживаемых автоматическими алгоритмами.
- Проверенные основные девять разделов не следует приравнивать к полной приёмке всех отдельных вложенных приложений, находящихся в репозитории.

**Итог:** версия `113a8c4b` прошла 235 браузерных тестов, полный статический контроль и проверку опубликованного сайта после развертывания; расширенная проверка 393 внешних URL завершилась без подтверждённых 404/410. **77 URL остаются непроверенными по существу**, а инженерные утверждения 51 профессии не получили индивидуальной независимой фактологической экспертизы. Измерения на настоящих слабых мобильных устройствах не проводились.
