# Список дел Ева / Дима / Кася — общая синхронизация

**Состояние:** HTML готов, клиент протестирован с имитацией сервера. Данные реального облака не подключены, пока не развёрнута отдельная функция Cloud Functions.

## Архитектура

- `index.html` — GitHub Pages, три независимых списка и этапы, локальная копия на каждом устройстве, экспорт/импорт JSON.
- `cloud` — отдельная Yandex Cloud Function, хранящая только список дел в YDB `app_state` по идентификатору `household-checklist-v1`.
- Существующее личное приложение `life/`, его ключ и запись `personal` не используются и не меняются.
- Авторизация через общий случайный ключ, проверяется SHA-256 на сервере. HTTPS + CORS на разрешённый домен.
- Обновление при открытой странице: при локальных изменениях и раз в 8 секунд, а также при возврате на вкладку или появлении сети. Это опрос, не WebSocket.
- Одновременные независимые изменения объединяются по ID задачи/этапа, конфликт одной и той же записи не перезаписывается автоматически. Запись с проверкой номера ревизии предотвращает потерю параллельных правок.

## Развёртывание — одноразовая настройка облака

1. Открой [Yandex Cloud Functions](https://console.yandex.cloud/), создай **отдельную** функцию `household-checklist-sync` в том же каталоге, где находится YDB от `life/` (не заменяй функцию `life-sync`).
2. В интерфейсе `index.html` нажми «Создать случайный ключ». Запиши сам ключ для второго телефона, скопируй SHA-256 в настройки функции.
3. Загрузи ZIP `household-checklist-cloud.zip`, выбери Node.js 22, точку входа `index.handler`, сервисный аккаунт, имеющий доступ к нужной базе YDB (например, уже настроенный `life-sync-sa`). Функции надо разрешить публичный вызов; **данные всё равно защищены ключом**. Это не защищает от расходов на вызовы без авторизации.
4. Заполни переменные окружения:
   - `CHECKLIST_TOKEN_SHA256`: скопированный SHA-256 из интерфейса (64 символа; не сам ключ)
   - `YDB_CONNECTION_STRING`: адрес той базы YDB, которую использует личная функция `life-sync` (из её настроек)
   - `ALLOWED_ORIGINS`: `https://vremennobeznika.github.io` (для домена `enjigirling.ru` можно указать через запятую ещё `https://enjigirling.ru`)
5. Сохрани функцию, скопируй HTTPS-ссылку `https://functions.yandexcloud.net/...`.
6. На [странице списка](https://vremennobeznika.github.io/enjigirling/checklist/) введи URL функции и ключ, нажми «Подключить». То же самое сделай на втором телефоне. Личную ссылку на саму страницу можно передавать через MAX, но общий секрет следует передавать отдельно.
7. Если первоначальные списки были в скачанном HTML, сначала нажми там «Скачать копию JSON», затем на веб-странице «Восстановить из копии» (на **первом** устройстве до подключения второго). На втором устройстве списки должны быть пустыми при первом подключении.

**Цена:** используется облачная функция и YDB. Стоимость зависит от числа обращений и условий тарифа. Проверяй квоты и биллинг Yandex Cloud, особенно из-за опроса каждые 8 секунд.

**Ограничения:** не проверялась реальная Yandex Cloud Function или физические телефоны; при закрытой странице обновления ждут открытия сайта. Ключ хранится в localStorage браузера и доступен пользователям с доступом к профилю устройства. Ключ нельзя публиковать в GitHub или передавать посторонним.

Документация: https://yandex.cloud/ru/docs/functions/operations/function/version-manage ; https://yandex.cloud/ru/docs/functions/lang/nodejs/dependencies
