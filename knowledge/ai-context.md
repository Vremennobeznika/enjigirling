### Процессы
- **Литьё** — Формирование заготовки заливкой расплава в форму. Подготовка формы → плавка → заливка → затвердевание → извлечение → контроль Усадочные дефекты, пористость, включения. Подробнее: https://vremennobeznika.github.io/enjigirling/processes.html#casting
- **Дуговая сварка** — Создание соединения с использованием электрической дуги. Выбор способа и присадочных материалов зависит от изделия. Подготовка → сборка → сварка → контроль Непровар, трещины, поры, деформации. Подробнее: https://vremennobeznika.github.io/enjigirling/processes.html#welding
- **Обработка резанием** — Формирование геометрии удалением материала режущим инструментом. Базирование → режимы резания → обработка → измерение Размеры, шероховатость, износ инструмента. Подробнее: https://vremennobeznika.github.io/enjigirling/processes.html#cutting
- **Термическая обработка** — Изменение структуры и свойств материала заданным тепловым циклом. Нагрев → выдержка → охлаждение → проверка Твёрдость, деформация, трещины; критерии зависят от марки. Подробнее: https://vremennobeznika.github.io/enjigirling/processes.html#heat
- **Аддитивное производство** — Послойное изготовление деталей по цифровой модели. Подготовка модели → изготовление → постобработка → контроль Геометрия, пористость, ориентация слоёв. Подробнее: https://vremennobeznika.github.io/enjigirling/processes.html#additive
- **Неразрушающий контроль** — Обнаружение несплошностей и других признаков дефектов без разрушения объекта контроля. Выбор метода → подготовка → контроль → оценка → протокол Чувствительность, доступность зон, ограничения метода. Подробнее: https://vremennobeznika.github.io/enjigirling/processes.html#inspection
- **MIG/MAG-сварка** — Дуговая сварка плавящимся электродом в защитном газе; MIG и MAG различаются типом защитной среды. Подготовка → настройка подачи проволоки и газа → сварка → контроль Поры, брызги, непровар, качество га…. Подробнее: https://vremennobeznika.github.io/enjigirling/processes.html#mig-mag
- **TIG-сварка** — Дуговая сварка неплавящимся вольфрамовым электродом в защитном газе. Подготовка → выбор электрода и присадки → сварка → контроль Защита сварочной ванны, геометрия шва, несплошности. Подробнее: https://vremennobeznika.github.io/enjigirling/processes.html#tig
- **Ультразвуковой контроль** — Метод НК на основе распространения ультразвуковых волн; применимость зависит от материала и геометрии. Выбор преобразователя → настройка → сканирование → интерпретация → протокол Мёртвые зоны, акустич…. Подробнее: https://vremennobeznika.github.io/enjigirling/processes.html#ultrasonic
- **Радиографический контроль** — Получение изображения внутренней структуры объекта с помощью проникающего излучения. Планирование → обеспечение радиационной безопасности → экспонирование → оценка → протокол Чувствительность, толщина…. Подробнее: https://vremennobeznika.github.io/enjigirling/processes.html#radiographic
- **Капиллярный контроль** — Обнаружение открытых на поверхность несплошностей с помощью проникающих веществ. Очистка → нанесение пенетранта → удаление → проявление → оценка Состояние поверхности, время выдержки, доступность дефе…. Подробнее: https://vremennobeznika.github.io/enjigirling/processes.html#dye
- **Измерение твёрдости** — Контроль сопротивления материала локальному вдавливанию выбранным методом.
