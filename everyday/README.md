# Обычный день — локальный органайзер

Самостоятельное приложение для обычного пользователя. **Не использует** пользовательскую панель `life/`, её расписание, 72 растения, секрет синхронизации или Yandex Cloud. Списки и финансовые записи сохраняются **исключительно в localStorage браузера** на текущем устройстве.

## Открыть приложение

<https://vremennobeznika.github.io/enjigirling/everyday/>

Приложение можно установить на телефон/ПК через меню браузера «Установить приложение» (если браузер поддерживает PWA). После первого полного открытия работает и без интернета благодаря service worker. Скрытых облачных синхронизаций нет.

## Разделы

- **Обзор:** задачи дня, расходы за текущий месяц, позиции для покупок, последние операции.
- **Календарь:** недельные дни, разовые задачи, ежедневные и еженедельные шаблоны с выбором конкретного дня недели, отдельные галочки по датам.
- **Финансы:** ручные доходы и расходы, категории, лимиты на месяц, отчёт по категориям, редактирование и удаление записей, CSV по выбранному месяцу, месячные регулярные счета и подписки.
- **Покупки:** товар, количество, пользовательская категория, отметка «куплено», очистка отмеченных.
- **Дом:** запасы, растения в произвольном количестве, записи ухода, повторяющиеся домашние дела.
- **Собственные разделы:** пользователь может добавить собственный список задач, скрыть/переименовать раздел и настроить пункты.
- **Настройки:** **единое место** настройки разделов, названий, повторяемых пунктов, категорий финансов, лимитов, подписок, категорий покупок, валюты, темы, экспорта и восстановления. В обычных вкладках нет редактирования структуры.

Наборы категорий — только отправная точка: можно переименовывать и добавлять свои. Неиспользуемые разделы скрываются. История расходов после переименования категорий сохраняется.

## Принципы безопасности и работы с деньгами

- Финансовые суммы сохраняются **целыми копейками/центами**, а не дробными числами. Ввод поддерживает запятую и точку, до двух знаков после разделителя.
- Все записи ведутся в одной выбранной валюте. После первого платежа, лимита или подписки изменение валюты блокируется. Встроенного валютного обмена нет.
- Регулярный платёж — это **шаблон**, он **не списывает** деньги автоматически. Отметка «Записать оплату» создаёт транзакцию один раз за выбранный месяц.
- Для категории расходов можно задать повторяющийся месячный лимит. Он не переносит остаток на следующий месяц автоматически.
- CSV использует защиту от формульного ввода (поля, похожие на формулы, записываются текстом).
- Введённые данные **не отправляются** на сторонние серверы. Исходники статичны, отсутствуют трекеры и удалённые API.

## Почему нужен экспорт

Данные хранятся **в конкретном браузере**. Второе устройство не синхронизируется само. Очистка данных сайта, переустановка браузера или его сброс могут удалить записи. Для переноса:

1. «Настройки» → «Скачать JSON-копию».
2. Перенести файл на другое устройство любым собственным способом.
3. На другом устройстве открыть приложение → «Настройки» → «Восстановить из JSON».

Импорт **заменяет**, а не объединяет записи. Перед импортом текущий снимок хранится в браузере как одна аварийная копия, если запись удаётся; кнопка «Вернуть прошлую копию» позволяет восстановить её. **Не полагайся только на эту аварийную копию:** скачивай JSON-файл регулярно.

## Для разработчика

```sh
node everyday/tests/model.test.cjs
npm install
npx playwright install chromium
npx playwright test --config everyday/playwright.config.cjs
```

Файлы: `index.html`, `style.css`, `model.js`, `app.js`, `sw.js`, `manifest.webmanifest`, `icon.svg`. Зависимостей в production нет.

GitHub Actions: [Ordinary Day — standalone app QA](https://github.com/Vremennobeznika/enjigirling/actions/workflows/everyday-qa.yml).

## Ограничения

- Нет общей учётной записи и облачного хранения. Редактирование на двух устройствах без переноса копий создаёт разные локальные версии.
- Нет фоновых системных напоминаний с гарантированной доставкой, пока браузер закрыт.
- Это личная ведомость доходов/расходов, а не полноценная бухгалтерская или банковская система.
- Режим инкогнито/приватные окна могут не сохранять данные между сеансами; браузер может ограничить хранилище.
- Растения и уход необязательны, никаких медицинских назначений приложение не даёт.
