# Матрица проверки личного приложения

**Область:** `/life/` (панель), `/calendar/` (неделя), `/shopping/` (покупки), `/plants/` (72 растения), YDB (синхронизация). Версия матрицы: 22.10.2026.

**Принцип:** тесты на GitHub Actions подтверждают поведение в изолированном браузере и симуляции YDB, **но не подменяют** проверки реального обмена личными данными между устройствами. Никогда не стирать локальные данные или перезаписывать облачную копию ради теста.

## Уровни контроля

- **S — статический / Node.js:** структура HTML, синтаксис JS, состав расписания, фиксация ID, чистота данных.
- **B — браузерный / Playwright:** реальная сетка, размеры, галочки, формы, хранение, переходы; без доступа к персональным данным.
- **M — моделирование:** GET/PUT YDB без учётных данных, версии, слияние, конфликты, восстановление.
- **L — реальная среда:** опубликованная GitHub Pages, авторизованный ключ на собственном устройстве, фактический YDB, внешний телефон. Нельзя считать пройденным по результату симуляции.

## Правило выпуска

1. Выполнить `node tests/life-sync.cjs` и `npx playwright test tests/calendar-layout.spec.cjs tests/life-layout.spec.cjs`; вся общая сборка GitHub Pages также должна завершиться без ошибок.
2. Проверить опубликованные `/life/`, `/calendar/`, `/shopping/`, `/plants/` **после** окончания публикации; смотреть реальные размеры, не только HTML.
3. Сделать резервную копию на устройстве с заполненными данными. Не тестировать «Очистить всё» или восстановление поверх пользовательских данных.
4. Реальный трёхсторонний тест YDB — отдельно, с тестовыми записями; до него не объявлять автоматическую синхронизацию полностью проверенной.

## Конструктивные ограничения

- Текущее облако предназначено одному владельцу, а не нескольким независимым пользователям.
- Хранение ключа в localStorage удобно, но не защищает его от человека с доступом к профилю браузера.
- Напоминания и фоновые задачи закрытого браузера не реализованы; статический сайт не умеет гарантировать системные уведомления.
- Добавки в расписании записаны по этикетке/инструкции, это не медицинское назначение.
