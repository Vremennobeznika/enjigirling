## Подключение второго, третьего и следующих устройств

1. Открыть <https://vremennobeznika.github.io/enjigirling/life/> на новом устройстве.
2. Ввести тот же **исходный** секрет (не SHA-256) и нажать «Применить». Это необходимо только при первом подключении данного браузера.
3. На **личном** устройстве отметить «Запомнить ключ на этом устройстве». В браузере будет сохранён сам секрет в `localStorage` без дополнительного шифрования. Не включать на общедоступных устройствах.
4. Отметить «Автоматически синхронизировать изменения». На пустом новом устройстве данные автоматически загружаются из облака. Если уже есть отличающиеся локальные данные, клиент **останавливается с предупреждением**, не стирая их.
5. На остальных личных устройствах выполнить те же действия по одному разу. Вход с нового устройства **без первого предъявления секрета не предусмотрен**: для этого потребовалась бы отдельная система авторизации/привязки устройств.

### Поведение при изменениях

- Изменения календаря, покупок, задач, домашних запасов и 72 растений отправляются автоматически спустя короткую паузу при работающей странице.
- При входе, возвращении на страницу, появлении сети и каждые две минуты **пока страница открыта** проверяются обновления в облаке. При закрытом браузере фоновой синхронизации нет: обновления применятся при новом открытии сайта.
- Сервер проверяет `revision` и не перезаписывает данные при ошибке 409. На клиенте при необходимости используется слияние по разделам и ID записей: независимые правки объединяются, конфликтующие изменения одной записи сохраняются локально с предупреждением.
- Перед автоматической заменой данных браузера сохраняется до двух **защитных копий** в `life-sync-recovery-v1`. Кнопка «Скачать защитные копии» в панели позволяет их экспортировать.
- Ручные «Отправить в облако» и «Получить из облака» оставлены. Перед ручной заменой запрашивается подтверждение. Дополнительно можно скачать обычную резервную копию всех разделов.
- На новом устройстве со своим локальным содержимым первая автоматическая синхронизация специально останавливается при расхождении, чтобы не выбирать победившую копию самостоятельно.

### Управление в браузере

- `life-sync-secret-v1` — временный ключ в `sessionStorage` текущей вкладки.
- `life-sync-secret-saved-v1` — постоянный ключ в `localStorage`, **только если включено «Запомнить ключ»**.
- `life-sync-auto-v1=on` — явное согласие на автосинхронизацию на этом устройстве; по умолчанию отключена.
- `life-sync-state-v2` — последняя общая ревизия и снимок для безопасного слияния.
- `life-sync-recovery-v1` — локальные защитные копии перед применением удалённых изменений.
- Кнопка «Отключить» удаляет сохранённый постоянный и временный ключ, а также выключает автосинхронизацию, не удаляя пользовательские списки/растения.

## Безопасность и ограничения

- Сервис рассчитан на одного владельца и общий приватный ключ, **не на независимые аккаунты пользователей**. При утечке ключ надо перевыпустить с изменением проверочного SHA-256 в функции.
- Код GitHub Pages публичен; содержимое персональных списков и исходный ключ **не хранятся в репозитории**.
- `localStorage` не является секретным хранилищем: доступ к браузерному профилю может раскрыть ключ. На чужом устройстве галочку «Запомнить» не включать.
- Для обращения к Cloud Functions с сайта функция публична, однако проверяет секрет в заголовке. **Секрет не защищает от расходов на неавторизованные обращения**: ограничить квоты и настроить уведомления Billing.
- Бюджет Yandex Cloud — оповещение, а не автоматический лимит остановки услуг. При превышении бесплатных лимитов возможна плата.
- Данные всегда сначала сохраняются локально. При отсутствии сети облачная синхронизация может отложиться; конфликт останавливает автоматическую замену, а не удаляет изменения.
