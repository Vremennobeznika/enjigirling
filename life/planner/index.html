Установка на Android

Chrome · локально · без аккаунта

В Chrome для Android открой меню ⋮ и выбери «Установить приложение» или «Добавить на главный экран». После первой загрузки приложение сможет открываться без сети. Данные этого устройства не передаются в облако.

Для напоминаний при полностью закрытом Chrome экспортируй .ics в календарь Android: локальный сайт не может гарантировать фоновую доставку и самовольно открывать вкладку.

Уведомления

Включаются отдельно для каждого пункта

Пока вкладка открыта, приложение проверяет расписание и показывает крупное напоминание. Системное уведомление требует разрешения браузера. Нельзя программно принудить браузер открыть вкладку на переднем плане; нажатие по уведомлению открывает или активирует приложение, если браузер это позволяет.

Календарь .ics создаёт события на следующие 30 дней для включённых пунктов расписания и по одному событию для незавершённых покупок с напоминанием. Это отдельная локальная копия расписания: изменения в приложении не отменяют уже импортированные события.

Данные и приватность

Без регистрации и синхронизации

Данные остаются в браузере этого устройства. Очистка данных сайта или приватный режим могут удалить их. Для переноса на другое устройство скачай JSON-копию и импортируй её там. Пароли и облако не используются.
