Локальный режим
Установить на iPhone — инструкция

Открой эту страницу в Safari → «Поделиться» → «На экран Домой» → включи «Открыть как веб-приложение» → «Добавить». Затем запускай «Сегодня» с иконки. Календарь, покупки и растения будут открываться внутри приложения.

После первоначальной загрузки страницы доступны без сети. Записи хранятся на устройстве; синхронизация с Яндексом работает отдельно, когда облако доступно.

        Управление данными

        Резервная копия всех разделов

        В копию входят отметки календаря, гибкий планировщик (включая финансы и напоминания), покупки, задачи, домашние запасы и журнал 72 растений. Можно восстановить и обычный экспорт, и файл «Скачать защитные копии». При восстановлении автосинхронизация отключается, чтобы избежать перезаписи.

        Облачная синхронизация · подключение Yandex Cloud

        База YDB и облачная функция уже созданы. Для синхронизации нужны правильный личный ключ и рабочий доступ функции к базе. Пока проверка не пройдена, данные остаются в браузере.

        Автосинхронизация выключена.

        На личном устройстве ключ останется после закрытия вкладки. Не включай на чужом компьютере: ключ хранится в браузере без дополнительного шифрования.

        Облако пока не подключено.

        При включённой автоматической синхронизации изменения отправляются в YDB, а более новые данные загружаются при открытии и возвращении на сайт. Конфликты блокируются, а защитные копии сохраняются в браузере. Ручные кнопки остаются. Если появилась ошибка подключения, проверь версию и сервисный аккаунт, затем доступ на вкладке «Обзор». Публичный вызов функции возможен только с дополнительным контролем расходов: неизвестные запросы тоже могут потреблять квоты. Данные сохраняются локально; ключ можно запомнить на личном устройстве. В GitHub он не отправляется.
